# Kalyan Portfolio

A modern and responsive personal portfolio website built with **React**, **Tailwind CSS**, and **Framer Motion** to showcase my projects, skills, and experience as a **Full Stack Developer**.

This portfolio highlights my expertise in **MERN stack, Django REST API, and AI integrations**, featuring dynamic project tabs, smooth animations, and an elegant design optimized for recruiters and hiring managers.

---

## Features

- **Hero Section** – Name, tagline, quick intro with CTA buttons (View Projects, Download Resume, Contact).
- **About Me** – Developer journey, tech stack overview, and professional goals.
- **Skills Showcase** – Categorized frontend, backend, database, and tools with icons.
- **Projects Section** – Dynamic project tabs (**Fullstack, Frontend, Backend**) populated from constants file.
- **Timeline** – Combined **Education & Work Experience** visual timeline.
- **Resume Section** – Resume highlights with direct **download/view PDF** links.
- **Contact Section** – Links to **GitHub, LinkedIn, Email** with optional form.
- **Responsive & Animated** – Optimized for mobile and desktop with smooth transitions.
- **Dark/Light Mode Ready** (via DaisyUI theming).

---

## Tech Stack

- **Frontend**: React (Vite) + TypeScript
- **Styling**: Tailwind CSS + DaisyUI + Framer Motion
- **State Management**: React Hooks
- **Icons**: React Icons
- **Deployment**: Vercel

## Setup & Run Locally

### 1. Clone Repository

```bash
git clone https://github.com/Kalyanpandaga/kalyan-portfolio.git
cd kalyan-portfolio
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start Development Server

```bash
npm run dev
```

App will run at `http://localhost:8080`
